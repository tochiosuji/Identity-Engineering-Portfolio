Enterprise Zero Trust Identity Programme
Organisation
Unigreen Bio

Project Overview
This project demonstrates the design of a Zero Trust Identity Architecture for Unigreen Bio using Microsoft Entra ID.

The objective is to strengthen identity security by implementing least privilege principles, strong authentication controls and structured administrative access.

Business Challenge
Unigreen Bio manages research, operational and administrative data across Microsoft cloud services.

The organisation requires a secure identity platform that:

Protects user accounts
Reduces privilege risk
Improves administrative control
Supports future governance initiatives
Security Objectives
Enforce Multi-Factor Authentication
Implement Role-Based Access Control
Define Administrative Access Boundaries
Create Emergency Access Procedures
Improve Security Monitoring
Status
In Progress
